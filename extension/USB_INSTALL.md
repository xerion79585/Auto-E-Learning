# USB 離線安裝說明

這份擴充功能可直接放在 USB 隨身碟中安裝，不需要先上架 Chrome Web Store，也不會從 GitHub 下載或執行 JavaScript。

## 安裝步驟

1. 將 USB 套件完整解壓縮到電腦的固定資料夾，例如「文件/學習小幫手」。不要直接在 ZIP 檔內載入。
2. 在 Chrome 開啟 `chrome://extensions`。
3. 開啟右上角的「開發人員模式」。
4. 點擊「載入未封裝項目」。
5. 選擇解壓縮後的 `extension` 資料夾，也就是含有 `manifest.json` 的資料夾。
6. 將「學習小幫手」固定到工具列，第一次使用時輸入啟用密碼。

## USB 使用限制

- 「離線安裝」表示不必使用 Chrome Web Store；實際登入課程、讀取白名單和下載題庫仍需要網路。
- Chrome 會從選取的資料夾載入擴充功能。不要刪除、改名或移動該資料夾，否則 Chrome 會停用這份載入項目；USB 被拔除後，Chrome 也可能無法重新載入它。
- 要更新 USB 版本時，先在 `chrome://extensions` 按「移除」，再選擇新版的 `extension` 資料夾。已啟用的使用者在同一個 Chrome 個人資料內通常仍保有本機啟用狀態，但不應依賴此行為作為資料備份。
- USB 安裝可供受控環境使用，但一般使用者可讀取未封裝擴充功能的檔案。Chrome 擴充功能無法可靠防止本機持有檔案的人檢視或修改程式碼；請把密碼、白名單和服務端授權視為真正的存取控制。
