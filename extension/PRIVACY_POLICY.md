# 學習小幫手隱私權政策

生效版本：1.1.0  
最後更新：2026-08-25

## 適用範圍

本政策適用於 Chrome 擴充功能「學習小幫手」。本擴充功能僅在 `https://elearn.hrd.gov.tw/` 運作，並以啟用密碼和 UID 白名單限制使用資格。

## 本機處理的資料

擴充功能會在使用者裝置的 Chrome 本機儲存空間中保存下列資料：

- 啟用狀態。
- 從目標網站頁面讀取的 UID 快取，用於本機白名單比對。
- 短期的白名單、設定和推薦課程資料快取。

啟用密碼只會傳送到擴充功能本機的 service worker 進行雜湊比對，不會傳送到開發者、Google、GitHub 或其他第三方，也不會以明文保存。

## 網路請求與資料來源

為執行功能，擴充功能會建立不含使用者 Cookie 的 HTTPS 請求，以讀取：

- 目標學習網站頁面已有的課程資訊。
- 公開 Google Sheets 的白名單和推薦課程資料。
- 指定 GitHub 儲存庫中的 JSON 設定和題庫資料。

這些請求不會附帶 UID、姓名、密碼、IP 位址、使用者代理字串、完整瀏覽紀錄或其他可識別使用者的內容。UID 僅留在本機，用來與已下載的白名單資料比對。

## 不會收集或分享的資料

本版本不會將姓名、UID、啟用密碼、IP 位址、使用者代理字串、頁面 URL、課程進度、考試答案或問卷內容傳送給開發者。擴充功能不使用廣告、分析追蹤、第三方通知服務或資料販售服務。

## 保留與刪除

本機資料會在擴充功能仍安裝時保留，以維持啟用狀態和離線快取。解除安裝擴充功能會由 Chrome 移除其本機儲存資料。白名單、題庫和設定快取會在後續讀取時依其有效時間更新。

## 外部服務

Google Sheets、GitHub 和目標學習網站各自依其隱私權政策處理連線請求。使用者登入目標學習網站後，網站本身如何處理帳號和課程資料，不受本擴充功能控制。

## 聯絡方式

可透過本專案的 GitHub Issues 頁面聯絡發布者：

`https://github.com/xerion79585/Auto-E-Learning/issues`

發布時，請將同一份政策部署到公開 HTTPS 網頁，並將該 URL 填入 Chrome Web Store 的隱私權政策欄位。
