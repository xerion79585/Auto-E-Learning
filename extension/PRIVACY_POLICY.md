# 學習小幫手隱私權政策

生效版本：1.1.2
最後更新：2026-08-28

## 適用範圍

本政策適用於 Chrome 擴充功能「學習小幫手」。本擴充功能僅在 HTTPS 的 `*.hrd.gov.tw` 學習平台網域運作；此範圍包含 `elearn.hrd.gov.tw` 首頁及可能由其他 HRD 子網域承載的課程 frame。擴充功能以啟用密碼和 UID 白名單限制使用資格。

## 本機處理的資料

擴充功能會在使用者裝置的 Chrome 本機儲存空間中保存下列資料：

- 啟用狀態。
- 從目標網站頁面讀取的 UID 快取，用於本機白名單比對。
- 短期的白名單、設定和推薦課程資料快取。

啟用密碼會透過 HTTPS 傳送到發布者管理的 Google Apps Script 驗證服務。服務只會比對私人 `PASS-KEY` 工作表；成功後在對應列寫入使用時間和（若有）UID，密碼本身不會回傳給擴充功能，也不會寫入使用者裝置。

## 網路請求與資料來源

為執行功能，擴充功能會建立不含使用者 Cookie 的 HTTPS 請求，以讀取：

- 目標學習網站頁面已有的課程資訊。
- 公開 Google Sheets 的白名單和推薦課程資料。
- 指定 GitHub 儲存庫中的 JSON 設定和題庫資料。
- 發布者管理的 Google Apps Script 一次性啟用密碼驗證端點。

白名單與 GitHub 請求不會附帶 UID、姓名、密碼、IP 位址、使用者代理字串、完整瀏覽紀錄或其他可識別使用者的內容。啟用驗證請求會附帶使用者輸入的密碼和目前頁面可取得的 UID，僅用於一次性密碼比對和啟用記錄。UID 不會送到白名單或 GitHub。

## 不會收集或分享的資料

本版本不會將姓名、頁面 URL、課程進度、考試答案或問卷內容傳送給發布者。啟用密碼和（啟用時）UID 只會送到發布者管理的 Apps Script 驗證服務，不會送到 GitHub、公開白名單或其他第三方。擴充功能不使用廣告、分析追蹤、第三方通知服務或資料販售服務。

## 保留與刪除

本機資料會在擴充功能仍安裝時保留，以維持啟用狀態和離線快取。解除安裝擴充功能會由 Chrome 移除其本機儲存資料。白名單、題庫和設定快取會在後續讀取時依其有效時間更新。

## 外部服務

Google Sheets、GitHub 和目標學習網站各自依其隱私權政策處理連線請求。使用者登入目標學習網站後，網站本身如何處理帳號和課程資料，不受本擴充功能控制。

## 聯絡方式

可透過本專案的 GitHub Issues 頁面聯絡發布者：

`https://github.com/xerion79585/Auto-E-Learning/issues`

發布時，請將同一份政策部署到公開 HTTPS 網頁，並將該 URL 填入 Chrome Web Store 的隱私權政策欄位。
