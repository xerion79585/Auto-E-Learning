學習小幫手隱私權政策

生效版本：1.1.4
最後更新：2026-09-02

適用範圍

本政策適用於 Chrome 擴充功能「學習小幫手」。本擴充功能僅在 HTTPS 的 *.hrd.gov.tw 學習平台網域運作；此範圍包含 elearn.hrd.gov.tw 首頁及可能由其他 HRD 子網域承載的課程 frame。擴充功能以啟用密碼和 UID 白名單限制使用資格。

本機處理的資料

擴充功能只會在使用者裝置的 Chrome 本機儲存空間保存啟用狀態、從目標網站頁面讀取的 UID 快取，以及白名單、設定和推薦課程的短期資料快取。

啟用密碼會透過 HTTPS 傳送到發布者管理的 Google Apps Script 驗證服務。服務只會比對私人 PASS-KEY 工作表；成功後在對應列寫入使用時間和（若有）UID，密碼本身不會回傳給擴充功能，也不會寫入使用者裝置。

網路請求與資料來源

為執行功能，擴充功能會建立不含使用者 Cookie 的 HTTPS 請求，以讀取公開 Google Sheets 的白名單與推薦課程資料、指定 GitHub 儲存庫內的 JSON 設定與題庫資料，以及向發布者管理的 Google Apps Script 驗證一次性啟用密碼。白名單通過後，Apps Script 會向發布者設定的私有 ntfy 主題傳送 UID 和時間通知，並以十分鐘冷卻時間避免重複通知。

白名單與 GitHub 請求不會附帶 UID、姓名、密碼、IP 位址、使用者代理字串、完整瀏覽紀錄或其他可識別使用者的內容。啟用驗證請求會附帶使用者輸入的密碼和目前頁面可取得的 UID，僅用於一次性密碼比對和啟用記錄。通知請求只附帶 UID；Apps Script 再將 UID 和時間送到發布者設定的 ntfy 主題。

不會收集或分享的資料

本版本不會將姓名、IP 位址、User-Agent、頁面 URL、課程進度、考試答案或問卷內容傳送給發布者。啟用密碼和（啟用時）UID 會送到發布者管理的 Apps Script 驗證服務；白名單通過通知中的 UID 和時間會由該服務送到發布者設定的 ntfy 主題。擴充功能不使用廣告、分析追蹤或資料販售服務。

保留與刪除

本機資料會在擴充功能仍安裝時保留，以維持啟用狀態和離線快取。解除安裝擴充功能會由 Chrome 移除其本機儲存資料。白名單、題庫和設定快取會在後續讀取時依其有效時間更新。

外部服務

Google Sheets、GitHub、Google Apps Script、ntfy 和目標學習網站各自依其隱私權政策處理連線請求。使用者登入目標學習網站後，網站本身如何處理帳號和課程資料，不受本擴充功能控制。ntfy 主題與存取 token 由發布者在 Apps Script 私有設定中管理，不會放在擴充功能中。
